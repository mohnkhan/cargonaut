# Implementation Plan: VFS Backends — Archives + Remote (SFTP/FTP)

**Branch**: `057-vfs-backends` | **Date**: 2026-06-19 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/057-vfs-backends/spec.md`

## Summary

Implement four new `VfsBackend` impls (`ZipFs`, `TarFs`, `SftpFs`, `FtpFs`) plus a `VfsRegistry` dispatch layer in `cargonaut-vfs`, then wire them into `cargonaut-core` (`App` + `PaneState`) and `cargonaut-ui-tui` (`ActiveDialog` + User Menu). Archives are gated behind the `archives` Cargo feature; SFTP/FTP behind `remote`. Both features are default-enabled. All code follows TDD (Constitution §II): red commit before green commit on every FR.

Research summary: see [research.md](research.md).

## Technical Context

**Language/Version**: Rust 1.76 (MSRV per workspace `Cargo.toml`)

**Primary Dependencies**:
- Archives (`archives` feature): `zip = "2.6"`, `tar = "0.4"`, `flate2 = "1.1"`, `bzip2 = "0.6"`, `xz2 = "0.1"` (xz2 wraps liblzma — C dep; acceptable on Linux CI)
- SFTP (`remote` feature): `russh = "0.61"` (feature `aws-lc-rs`), `russh-sftp = "2.1"` (v2.1.2, CVE patch)
- FTP (`remote` feature): `suppaftp = "8"` (feature `tokio`)
- Existing: `tokio`, `async-trait`, `futures`, `tracing`, `thiserror`, `bitflags`, `smol_str`, `smallvec`

**Storage**: No new persistent storage; archive index is in-memory per `ZipFs`/`TarFs` instance; debug log appended to `~/.local/share/cargonaut/debug.log`

**Testing**: `cargo test --workspace`; `tokio::test` for async; `tempfile` for on-disk fixtures; mock `VfsBackend` trait objects for remote backends (no live servers in CI); `proptest` for VfsPath encoding round-trips

**Target Platform**: Linux x86_64 (same as existing binary)

**Performance Goals**:
- SC-001: ≤500 ms to list up to 10 000 archive entries (criterion bench)
- SC-003: ≤3 s SFTP connect + root listing (manual / integration gate)
- SC-004: ≥70% theoretical bandwidth for SFTP transfers ≥10 MiB (manual)
- SC-008: ≤1.5 MiB binary size increase with both features vs baseline

**Constraints**:
- No `libssh2` or C SSH deps (libssh2 is banned; xz2/liblzma is accepted)
- `VfsBackend` trait must remain object-safe (enforced by `tests/dyn_dispatch.rs`)
- Constitution §V: all build artifacts in tmpfs
- `#![warn(missing_docs)]` on all crates

### Phase B — ZIP Backend (US1, FR-004..FR-007)

**B1 — `ZipFs` + index** (`cargonaut-vfs/src/archive/zip_fs.rs`)
- `ZipFs::open(archive_host_path: PathBuf) -> Result<Self, VfsError>` — `spawn_blocking`, open file, `ZipArchive::new`, scan all entries via `enclosed_name()` (skips unsafe paths silently), build `Vec<ZipEntryMeta>` + `HashMap<String, usize>` name→index
- `impl VfsBackend for ZipFs`: `scheme()="zip"`, `caps()=VfsCaps::empty()`
- `list(path)`: decode authority → host path (validate matches `self.archive_path`); segments → entry path prefix; filter index entries; return `DirListing`
- `stat(path)`: lookup in index; return `VfsMetadata`
- `read_stream(path, ByteRange::FULL)`: `spawn_blocking`, open archive, seek to entry by name, `read_to_end`; non-FULL range → `VfsError::Unsupported`
- Write ops → `VfsError::Unsupported`
- Error mapping: `ZipError::UnsupportedArchive("Password")` → `PermissionDenied`; other → `Io`

**B2 — `ZipFs` unit tests** (`tests/zip_fs.rs`)
- list root, list subdirectory, stat file, read_stream byte-match, encrypted → PermissionDenied, corrupt → Io, range read → Unsupported

**B3 — UI: Enter → ZIP open** (`cargonaut-ui-tui/src/lib.rs`)
- In `DescendOrOpen` / `Command::Descend` handler: if focused entry is a regular file ending `.zip`, call `ZipFs::open(host_path)`, build `zip://…/` `VfsPath` (authority = percent-encode(archive host path), segments=[]), call `navigate_to(id, vfs_path, Arc::new(zip_fs))`
- Pane header in `chrome.rs`: if `pane.backend.scheme() != "file"`, display `pane.cwd.display()` in the header

**B4 — Backspace at archive root → local parent**
- `navigate_up(id)`: if `pane.cwd.segments.is_empty()` and `pane.backend.scheme() != "file"`, decode authority → host path, compute local parent directory, navigate to it with `registry.local()`
- Unit test: navigate up from `zip://` root → pane.cwd is `file://` parent directory

### Phase C — TAR Backend (US2, FR-008..FR-012)

**C1 — `TarFs` + index** (`cargonaut-vfs/src/archive/tar_fs.rs`)
- `TarCompression` enum: `None`, `Gz`, `Bz2`, `Xz`
- `TarFs::open(archive_host_path: PathBuf, compression: TarCompression) -> Result<Self, VfsError>`
- On open (`spawn_blocking`): scan all entries, drain each (`io::copy(&mut e, &mut sink())`), record `(entry_path_string, entry_index: usize, size, mtime, entry_type, link_target)`. Skip entries where `is_safe_path()` returns false (log at `WARN`).
- `read_stream(path, ByteRange::FULL)`: re-open file, re-scan from entry 0 counting to target entry by name, stream entry bytes; non-FULL range → `VfsError::Unsupported`
- `scheme()="tar"`, `caps()=VfsCaps::empty()`
- Write ops → `Unsupported`

**C2 — `TarFs` unit tests** (`tests/tar_fs.rs`)
- list/stat/read for .tar, .tar.gz, .tar.bz2, .tar.xz; path traversal entry skipped; corrupt → Io

**C3 — UI: Enter → TAR open**
- Extend `DescendOrOpen` to recognise `.tar`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tbz2`, `.tar.xz`, `.txz`; detect compression from extension; `TarFs::open(path, compression)`

### Phase D — SFTP Backend (US3, FR-013..FR-017, FR-030)

**D1 — `SftpCredentials` + `SftpFs::connect`** (`cargonaut-vfs/src/remote/sftp_fs.rs`)
- `SftpCredentials` enum: `PublicKey { use_agent: bool, key_path: Option<PathBuf> }`, `Password(String)`
- `HostKeyVerifySender = tokio::sync::oneshot::Sender<bool>`
- `SftpFs::connect(authority: &str, credentials: SftpCredentials, config: &SftpConfig, host_key_tx: HostKeyVerifySender) -> Result<Self, VfsError>`
  - Parse `user@host:port`; TCP connect with timeout; russh handshake with custom `HostKeyHandler`
  - `HostKeyHandler`: checks `~/.ssh/known_hosts` via `russh::keys::check_known_hosts`; if unknown, sends fingerprint + oneshot-sender to UI, awaits bool response; on Accept calls `russh::keys::learn_known_hosts_path`
  - Authenticate: ssh-agent → key file → password (in order)
  - Open SFTP channel; `SftpSession::new`
- Internal: holds `Handle<HostKeyHandler>` + `SftpSession`
- `tracing::info!("sftp connected to {}")`, `tracing::warn!` on retry/fail

**D2 — `SftpFs` `VfsBackend` impl**
- All operations via `SftpSession` async methods
- `read_stream(path, range)`: `sftp.open(path)` → `file.seek(SeekFrom::Start(range.start))` + async read; `file.shutdown().await` on drop
- `write_stream(path, offset, Truncate)`: open with `CREATE|TRUNCATE|WRITE` flags; `AppendAtOffset`: open with `WRITE` + `seek(SeekFrom::Start(offset))`
- Reconnect: `with_retry(3, backoff=[200ms,400ms,800ms], f)` on `Io`/transport errors
- `caps()` → `SEEKABLE | RANDOM_WRITE | METADATA_RICH | ATOMIC_RENAME | SYMLINKS`

**D3 — `SftpFs` tests** (mock-based via trait injection)
- Auth failure → `VfsError::AuthFailed`; list/stat/read/write/unlink/rename/mkdir via injected mock session; reconnect on transport error

**D4 — `AppEvent::HostKeyVerification` + `ActiveDialog::HostKeyVerify`**
- New `AppEvent::HostKeyVerification { fingerprint: String, accept_tx: oneshot::Sender<bool> }` in `cargonaut-core`
- New `ActiveDialog::HostKeyVerify { fingerprint: String, accept_tx: ... }` in TUI
- `HostKeyVerifyDialog` widget in `dialog.rs`: shows fingerprint + "Accept" / "Reject" buttons
- On Accept: `accept_tx.send(true)` (key already written to known_hosts by the handler)
- On Reject: `accept_tx.send(false)` → `SftpFs::connect` returns `VfsError::AuthFailed` → pane banner

**D5 — F2 menu → "Connect SFTP…"**
- Add system-level built-in menu item in the `ShowUserMenu` handler (separate from user `menu.toml`)
- Opens `ActiveDialog::RemoteConnect { kind: Sftp, widget: PathInputDialog::new("sftp://user@host/") }`
- On submit: parse URL, update pane header to "Connecting…", call `SftpFs::connect`, add to `registry`, `navigate_to` pane
- On error: dismiss RemoteConnect, show error banner in pane

### Phase E — FTP Backend (US4, FR-018..FR-020)

**E1 — `FtpFs`** (`cargonaut-vfs/src/remote/ftp_fs.rs`)
- `FtpFs::connect(authority: &str, user: &str, pass: &str, config: &FtpConfig) -> Result<Self, VfsError>`
- Internal: `Arc<Mutex<AsyncFtpStream>>` (serializes all ops)
- `list(path)`: try `mlsd()` → parse `ListParser::parse_mlsd`; fall back to `list()` → `ListParser::parse_posix`
- `stat(path)`: `mlst()` → `VfsMetadata`; unavailable fields → `None`
- `read_stream`: `retr_as_stream`; only `ByteRange::FULL` (range → Unsupported)
- `write_stream(Truncate)`: `put_with_stream`; `AppendAtOffset` → Unsupported
- `unlink`, `rmdir`, `rename`, `mkdir`
- `caps()` → `ATOMIC_RENAME` only
- `tracing::info!` on connect; `tracing::warn!` on error

## Key Design Decisions

| Decision | Choice | Rationale |
|---|---|---|
| Archive path encoding | Authority = percent-encoded host path; segments = entry path | Unambiguous boundary; no extension-scanning heuristic |
| ZipFs SEEKABLE | Not declared | Byte-range reads require full decompress; capability honesty (spec clarification) |
| Archive entry cache | In-memory on first `list()` | Avoids re-scanning multi-MB archive on every navigation |
| SFTP library | russh 0.61 + russh-sftp 2.1.2 | Only pure-Rust async SSH; 2.1.2 patches CVE-2026-46673 |
| FTP library | suppaftp 8 | Only maintained async FTP client; first-class MLSD |
| Cargo features | `archives` + `remote` (default-on) | User-facing grouping; both enabled in default build |
| Host-key UI | Blocking modal via oneshot channel | Matches ssh(1) TOFU; prevents silent auto-accept |
| FTP concurrency | Single Mutex-guarded connection | FTP architectural limit; pool deferred |
| Registry keying | scheme for singletons; `scheme://authority` for remotes | Archives ephemeral (in PaneState); remotes persistent |
| Archive backends in registry | NOT stored | Ephemeral per-file; held by PaneState.backend directly |
| xz2 liblzma dep | Accepted | liblzma universally available on Linux; no cross-compile concern |
