# Implementation Plan: PTY Binary-Level Navigation Smoke Test

**Branch**: `045-pty-nav-smoke-test` | **Date**: 2026-06-17 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/045-pty-nav-smoke-test/spec.md`

## Summary

Replace the `#[ignore]`d `local_navigation_smoke` stub in
`crates/cargonaut-bin/tests/local_navigation.rs` with three real PTY-driven tests
(T1.07, issue #30):

- **`nav_cursor_arrow_keys`** — arrow keys advance and retreat the cursor; asserted
  via the per-pane mini-status line using a delta-buffer approach.
- **`nav_descend_enter`** — Enter on a directory entry changes the active pane's CWD.
- **`nav_ascend_backspace`** — Backspace returns the pane to the parent directory.

All three gate on `CARGONAUT_PTY_TESTS=1` (self-skip otherwise). Shared PTY
helpers are extracted to a `tests/common/mod.rs` module so both this file and
`resume_sigkill.rs` can import them. No CI changes: the workflow already sets
the gate variable. No new crates. No production-code changes.

## Technical Context

**Language/Version**: Rust (workspace edition 2021, MSRV 1.76, same toolchain
as the rest of the workspace).

**Primary Dependencies**: `portable-pty = "0.8"` (workspace dep, already in
`cargonaut-bin` `[dev-dependencies]`), `tempfile = "3"` (same). No new crates.

**Storage**: N/A — tests create temporary directories via `tempfile::tempdir()`;
they are cleaned up on drop.

**Testing**: `cargo test --workspace --tests` with `CARGONAUT_PTY_TESTS=1`.
Gate self-skips when env var is absent. Constitution §II TDD discipline applies:
failing tests committed first, then the implementation that makes them pass.

**Target Platform**: Unix (Linux). `#[cfg(unix)]` guards the test file, consistent
with `resume_sigkill.rs`.

**Project Type**: Integration test within the `cargonaut-bin` crate. No changes
to any production crate.

**Performance Goals**: Each test must complete within a 30-second wall-clock
deadline (CI runner budget). Individual assertion polls use a 5-second deadline
per FR-006/SC-002.

**Constraints**: No `unsafe`. The shared helper module must not be compiled as a
standalone test binary (use `tests/common/mod.rs` inside `tests/common/` — Cargo
ignores `mod.rs` files as test roots). No SSD impact: integration tests write only
to `tempfile` directories (not to `target/`).

**Scale/Scope**: Approximately 200 LOC net addition across `local_navigation.rs`
and the new `tests/common/mod.rs`. The existing `resume_sigkill.rs` is refactored
to import helpers from `tests/common/` (net change ~−40 LOC by removing duplicates).
